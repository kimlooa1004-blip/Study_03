# 상식 퀴즈 웹 앱 PRD

## 1. 개요

| 항목 | 내용 |
|---|---|
| 한 줄 요약 | 대학 1학년 학생이 혼자 상식을 공부하며 푸는 4지선다 퀴즈 웹 앱 |
| 목적 | 틀린 문제를 그 자리에서 알고 넘어가게 한다 |
| 핵심 장치 | 답을 고르면 곧바로 정답 여부와 한 줄 해설을 보여 준다 |
| 실행 환경 | 브라우저에서 `index.html`을 열면 동작한다. 서버가 없다 |
| 파일 구성 | `index.html`, `style.css`, `script.js`, `questions.js` (4개) |

### 사용자

- 대학 1학년 학생 1명이 혼자 사용한다. 계정, 로그인, 다른 사람과의 경쟁은 없다.
- 순위표는 자기 브라우저 안의 기록끼리만 비교한다.

### 성공 기준

- 학생이 답을 고른 직후 정답 여부와 해설을 보고, 다음 문제로 넘어갈 수 있다.
- 10문제가 끝나면 점수가 표시된다.
- 40문제 모두 [6. 문항 규칙](#6-문항-규칙)을 만족한다.
- 서버나 빌드 없이 파일을 열기만 해도 모든 기능이 동작한다.

### 범위 밖

- 서버, 계정, 네트워크 통신
- 닉네임 입력, 여러 사용자 구분
- 카테고리 4개와 문항 40개를 넘는 확장
- 문항 편집 화면 (문항은 `questions.js`를 직접 수정한다)

## 2. 콘텐츠

- 카테고리 4개: 한국사, 세계지리, 과학, 예술과 문화
- 카테고리마다 10문제, 총 40문제
- 한 판은 카테고리 1개의 10문제를 푸는 것이다
- 10문제가 끝나면 점수를 보여 준다

## 3. 게임 모드

### 3.1 공통 규칙

- 답을 고르면 선택이 잠기고, 곧바로 정답 여부와 한 줄 해설을 보여 준다.
- 해설을 본 뒤 [다음]을 눌러 다음 문항으로 간다. 마지막 문항에서는 결과 화면으로 간다.
- 틀린 문항은 모든 모드에서 0점이다.

### 3.2 연습

| 항목 | 규칙 |
|---|---|
| 시간 제한 | 없음 |
| 힌트 | 없음 |
| 점수 | 맞히면 1점 (한 판 최대 10점) |
| 순위표 | 기록하지 않는다 |
| 안내 문구 | 시작 화면과 결과 화면에 "순위표에 기록되지 않음"을 표시한다 |
| 틀린 문제 다시 풀기 | 결과 화면에서 틀린 문항만 한 번 더 푸는 보충 라운드를 시작한다 (아래 참고) |

**틀린 문제 다시 풀기**

- 결과 화면의 [틀린 문제 다시 풀기]를 누르면 틀린 문항만 한 번 푼다.
- 보충 라운드가 끝나면 "다시 맞힌 개수 / 다시 푼 개수"를 보여 준다. 다시 틀린 문항은 한 번 더 풀지 않는다.
- 다시 푸는 것은 점수에 반영하지 않는다. 원래 판의 점수가 그대로 남는다.
- 틀린 문항이 없으면 버튼을 보여 주지 않는다.
- 연습 모드에만 있는 기능이다.

### 3.3 스피드

| 항목 | 규칙 |
|---|---|
| 제한 시간 | 문항마다 15초 |
| 시간 초과 | 오답으로 처리한다 (0점). 정답과 해설을 보여 준다 |
| 타이머 정지 | 답을 고르거나 시간이 지나 해설이 나오면 멈춘다 |
| 타이머 재시작 | [다음]을 누르면 다음 문항에서 15초부터 다시 센다 |
| 점수 | 맞히면 1점 (한 판 최대 10점) |
| 순위표 | 기록한다 |

### 3.4 힌트

| 항목 | 규칙 |
|---|---|
| 힌트 횟수 | 문항마다 1번 |
| 힌트 효과 | 누르면 오답 보기 2개를 지운다. 정답 보기와 오답 1개가 남는다 |
| 시간 제한 | 없음 |
| 점수 | 힌트 없이 맞히면 1점, 힌트를 쓰고 맞히면 0.5점 (한 판 최대 10점) |
| 순위표 | 기록한다 |

점수는 0.5 단위로 표시한다 (예: 7.5점).

## 4. 화면과 흐름

| 화면 | 내용 | 도입 단계 |
|---|---|---|
| 시작 | 카테고리 선택. 연습 모드이므로 "순위표에 기록되지 않음"을 표시한다 | 1단계 |
| 모드 선택 | 연습 / 스피드 / 힌트 선택. 모드별 규칙을 간단히 안내한다 | 2단계 |
| 문제 | 문항 번호(예: 3 / 10), 문제, 보기 4개. 스피드는 남은 시간, 힌트는 [힌트] 버튼을 표시한다 | 1단계 (모드별 요소는 2단계) |
| 해설 | 정답 여부, 정답, 한 줄 해설, 출처, [다음] | 1단계 |
| 결과 | 점수(예: 7 / 10), 모드별 안내. 연습은 "순위표에 기록되지 않음"과 [틀린 문제 다시 풀기] | 1단계 (다시 풀기는 2단계) |
| 순위표 | 모드·카테고리 탭으로 상위 10개 조회 | 3단계 |

2단계 이후 흐름: 모드 선택 → 카테고리 선택 → 문제 → 해설 → … → 결과. 결과 화면에서는 같은 설정으로 다시 하기와 처음으로 돌아가기를 고를 수 있다.

## 5. 구현 단계

### 1단계: 연습 모드와 점수

- 시작 화면에서 카테고리를 고르면 연습 모드로 바로 시작한다 (모드 선택 화면 없음)
- 10문제 진행, 즉시 정답 여부와 해설 표시, 맞히면 1점, 결과 화면에 점수 표시
- "순위표에 기록되지 않음" 문구를 시작 화면과 결과 화면에 표시한다
- 틀린 문제 다시 풀기는 아직 만들지 않는다

### 2단계: 스피드·힌트 모드, 모드 선택, 틀린 문제 다시 풀기

- 모드 선택 화면 추가
- 스피드 모드: 15초 타이머, 시간 초과는 오답, 해설 시 정지, [다음]에서 재시작
- 힌트 모드: 문항당 1회, 오답 보기 2개 제거, 힌트 사용 후 정답은 0.5점
- 연습 모드의 틀린 문제 다시 풀기 (3.2 참고)

### 3단계: 점수 저장과 순위표 (localStorage)

- 스피드·힌트 모드는 한 판이 끝날 때 자동으로 기록한다. 연습은 기록하지 않는다
- 기록 항목은 점수와 날짜이다. 닉네임은 받지 않는다
- 순위표는 **모드별 × 카테고리별**로 따로 둔다 (스피드·힌트 2개 모드 × 4개 카테고리 = 8개)
- 보관은 순위표마다 상위 10개이다. 점수가 높은 순이고, 동점이면 최근 기록이 위로 간다
- 시작 화면에서 순위표를 열 수 있고, 모드·카테고리 탭으로 전환한다
- localStorage를 쓸 수 없는 환경(차단, 시크릿 모드 등)에서는 기록 없이 게임은 정상 동작하고, "기록을 저장할 수 없음" 안내를 표시한다

## 6. 문항 규칙

모든 문항(40개)은 아래 세 가지를 만족해야 한다.

1. **정답은 하나만이어야 한다.** 보기 4개 중 정답이 정확히 1개이고, 나머지 3개는 명백히 틀려야 한다.
2. **해설에는 확인한 출처를 명시한다.** 작성자가 실제로 확인한 자료의 출처명(필요하면 URL)을 해설과 함께 적는다. 확인하지 않은 출처를 적거나 지어내지 않는다.
3. **최상급 표현("가장 ~한" 등)이 쓰인 문항은 기준과 시점을 문제에 명시한다.** 기준과 시점에 따라 답이 달라지기 때문이다. 예: "2024년 기준 면적이 가장 큰 나라는?"처럼 쓴다.

### 문항 데이터 형식 (`questions.js`)

```js
{
  id: "history-01",
  category: "한국사",
  question: "...",
  choices: ["...", "...", "...", "..."],
  answer: 0,            // choices의 인덱스, 정답은 하나
  explanation: "...",   // 한 줄 해설
  source: "..."         // 확인한 출처
}
```

### 문항 검수 체크리스트

- [ ] 카테고리마다 정확히 10문항, 총 40문항
- [ ] 보기가 4개이고 `answer`가 하나의 유효한 인덱스를 가리킨다
- [ ] 정답이 하나뿐임을 확인했다 (다른 보기가 부분적으로 맞는 경우가 없다)
- [ ] 해설에 한 줄 설명과 확인한 출처가 있다
- [ ] 최상급 표현이 있는 문항은 문제에 기준과 시점이 적혀 있다
- [ ] 시간이 지나 답이 바뀔 수 있는 문항(통계, 기록, 직위 등)은 기준 시점이 적혀 있다

## 7. 비기능 요구사항

- 서버 없이 `file://`로 `index.html`을 열어 동작한다. 외부 라이브러리와 네트워크 요청이 없다
- 데이터는 `questions.js`에 있고, 로직은 `script.js`, 화면은 `index.html`과 `style.css`에 둔다
- 최신 데스크톱 브라우저(Chrome, Edge, Safari, Firefox)에서 동작한다. 모바일 화면도 읽기 쉽게 보여야 한다
- 보기는 키보드로도 선택할 수 있어야 한다

## 8. 정해지지 않은 사항

아래는 요구에 명시되지 않아 다음과 같이 가정했다. 바꾸고 싶으면 알려 주면 된다.

| 사항 | 가정 |
|---|---|
| 스피드 모드 점수 | 맞히면 1점 |
| 힌트 없이 맞힌 점수 | 1점 |
| 힌트 모드의 시간 제한 | 없음 |
| 문항·보기 순서 | 문항 순서는 판마다 섞고, 보기 순서는 고정한다 |
| 시간 초과 시 | 오답으로 기록하고 정답과 해설을 보여 준 뒤 [다음]을 기다린다 |
| 도중에 나가기 | 진행 중인 판은 저장하지 않고, 다시 시작하면 처음부터 한다 |
| 날짜 표기 | 기록한 날짜를 `YYYY-MM-DD`로 표시한다 |
| 40문항 작성 | PRD와 별개의 작업이다. 작성 시 출처를 실제로 확인한다 |
